あらゆる PDF を、
あなたの言語で。

KenjaPDF は翻訳を内蔵した Mac 用 PDF リーダーです。 書類をドラッグしてワンタップ——原文と訳文が並んで表示されます。 スクロールは同期、レイアウトは保持、アップロードは一切なし。

近日 Mac App Store で公開予定 翻訳には macOS 26+ · アカウントもキーも不要
01

二ステップ、静かなウィンドウひとつ。

外国語の PDF から対訳リーディングまで、アプリの外に出ることなく——読んで、翻訳して、書き出す。

ステップ 01 · 読書

クリーンでミニマルなリーダー

PDF をウィンドウにドラッグ、または ⌘O。連続スクロール、折りたたみできるサイドバー（サムネイル＋アウトライン）、自由なズーム、ページラベル、印刷 ⌘P——パスワード保護されたファイルも入力を求めてロック解除します。

ステップ 02 · 翻訳

原文と訳文を、並べて

言語ペアを選び（原文言語は自動検出）、「翻訳」を押すだけ。Apple のオンボードエンジンが書類全体を翻訳し、結果は原文の隣に同期スクロールで開きます。ボタンひとつで二段組 / 訳文のみ / 原文のみを切り替え、訳文 PDF や原文・訳文交互のバイリンガル PDF として書き出せます。

02

母語ではない文書を読む人のために

クラウドのダッシュボードではありません——2 つのことをきちんとこなす、小さなネイティブ Mac ツールです。

翻訳

常に端末上で

翻訳は Apple のシステムエンジンが Mac の上で実行します。書類がアップロードされることはありません。言語ペアの初回翻訳時に、macOS 自身が小さな言語パックをダウンロードする場合があります。

言語

20 以上の言語を自動検出

原文言語は自動認識（手動指定も可）。翻訳先はシステムの優先言語がデフォルトで、対応リストは macOS から直接取得、表示名はお使いのロケールに従います。

同期

二段組、息の合ったスクロール

原文と訳文は双方向で同期スクロールし、ズームもパネル間でミラーされます。ボタンひとつで二段組 / 訳文のみ / 原文のみを巡回切り替え。

レイアウト

ページは元のまま

訳文は各段落の元の矩形に書き戻されます。ジオメトリ・余白・ベクターグラフィックはそのまま——訳文は原文と同じ版面で読めます。

数式

数式は数式のまま

数式行（LaTeX、MathType、Cambria Math フォント）を検出してそのまま残し、周囲の本文だけを翻訳。論文やレポートのために：数式を壊すくらいなら、その行は翻訳しません。

書き出し

訳文を持って歩く

訳文のみの PDF、または原文ページと訳文ページを交互に並べたバイリンガル版を書き出せます。どこでも読めて、プレビューで注釈でき、そのまま共有できます。

03

プライバシーはデフォルトで

アカウントなし。アップロードなし。トラッキングなし。

KenjaPDF は良い道具らしく振る舞います——あなたのマシンで仕事をして、誰とも通信しません。翻訳は Apple のオンボードエンジンで実行されるため、書類が Mac の外に出ることはありません。ログインするものも、漏洩するものもありません。

04

よくある質問

KenjaPDF は書類をどこかにアップロードしますか？

いいえ。閲覧・レイアウト解析・翻訳はすべて Mac 上で実行され、翻訳には Apple のシステム内蔵エンジンを使います。アカウントも分析もトラッキングもなく、App Store のプライバシーラベルは「データ収集なし」です。

どの言語に翻訳できますか？

macOS のシステム翻訳による 20 以上の言語に対応し、対応リストはシステムから直接取得します。原文言語は自動検出（手動指定も可）、翻訳先はシステムの優先言語がデフォルトです。言語ペアの初回翻訳時に、macOS が小さな言語パックをダウンロードする場合があります。

アカウントや API キーは必要ですか？

不要です。翻訳には macOS 内蔵のエンジンを使うため、サインインも API キーもサブスクリプションもありません。言語パックがない場合は、システムによる一回限りのダウンロードを案内して、そのあと自動で再試行します。

元のレイアウトは保持されますか？

はい。訳文はページのコピー上で各段落の元の位置に書き戻されるため、ジオメトリ・余白・ベクターグラフィックはそのまま残ります。数式行は自動検出してそのまま保持するため、翻訳後も数式は壊れません——論文や文献で特に重要です。

スキャンした PDF にも対応しますか？

KenjaPDF が翻訳するのは PDF のテキスト層です。テキストが埋め込まれていない画像のみのスキャンは、このバージョンでは翻訳できません——先に OCR におかけください。

動作環境を教えてください。

オンボード翻訳には Apple の Translation フレームワークを使用するため、macOS 26 以降が必要です。閲覧・アウトライン・書き出しは macOS 13 以降で動作します。
